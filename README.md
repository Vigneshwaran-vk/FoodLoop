# FoodLoop - Smart Food Surplus Redistribution

**Turning Surplus Food into a Shared Resource, Not Waste.**

FoodLoop is a technology-driven food redistribution platform that connects restaurants, hotels, supermarkets, event organizers, NGOs, and community kitchens to redistribute surplus edible food to people in need. By leveraging location-based matching and real-time coordination, FoodLoop aims to reduce food waste, improve food accessibility, and promote sustainable communities.

## Problem Statement

Every day, restaurants, retailers, and event organizers may have surplus edible food, while vulnerable communities struggle to access nutritious meals. The lack of a centralized platform for discovering, coordinating, and tracking food donations can lead to avoidable food waste and missed opportunities to help people in need.

FoodLoop bridges this gap by creating a digital ecosystem for efficient, safe, and transparent food redistribution.

## Our Solution

FoodLoop provides a centralized platform where food donors can list surplus food and verified NGOs or community kitchens can discover and request available donations.

The platform helps coordinate the redistribution process through location-based matching, food quantity and expiry information, pickup scheduling, notifications, and donation status tracking.

## Key Features

- **Food Donation Listings:** Donors can list surplus food with quantity, food type, preparation time, and pickup details.
- **Location-Based Matching:** Connect available food with nearby NGOs and community kitchens.
- **Recipient Verification:** Support a trusted network of eligible food collection organizations.
- **Food Freshness Tracking:** Display preparation time, collection deadlines, and relevant food safety information.
- **Smart Pickup Scheduling:** Coordinate collection times between donors and recipients.
- **Real-Time Notifications:** Notify users about new donations, requests, confirmations, and pickup updates.
- **Donation Tracking:** Track donations from listing and acceptance to collection and completion.
- **Impact Dashboard:** Display meals redistributed, donations completed, and estimated food waste avoided.
- **Responsive Interface:** Provide a user-friendly experience across desktops, tablets, and mobile devices.

##  How It Works

1. **Register:** Food donors and recipient organizations create accounts.
2. **List Surplus Food:** Donors publish available food, quantities, and collection deadlines.
3. **Discover Donations:** Nearby verified recipients browse available food.
4. **Match and Confirm:** Recipients request donations, and donors confirm collection.
5. **Collect Food:** Both parties coordinate the pickup within the specified time.
6. **Track Impact:** Completed donations contribute to the platform's impact dashboard.

##  Getting Started

### Prerequisites

Install the following tools before running the project:

- Node.js and npm
- PostgreSQL
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/FoodLoop.git
   cd FoodLoop
   ```

2. Install dependencies in the frontend and backend directories according to the project's package files.

3. Configure your environment variables using a local `.env` file. Do not commit secrets or credentials.

4. Configure the PostgreSQL database and apply the project's database migrations.

5. Start the backend and frontend using their respective development scripts.

> **Note:** Update these instructions with the actual folder structure, environment variables, database migrations, and commands used in your implementation.
